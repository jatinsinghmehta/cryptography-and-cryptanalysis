# Cryptography & Cryptanalysis Toolkit

A full-stack cybersecurity project implementing classical cryptography
and basic cryptanalysis techniques.

## Features
- Caesar Cipher Encryption
- Caesar Cipher Decryption
- Caesar Cipher Brute Force
- Vigenère Cipher Encryption
- Vigenère Cipher Decryption
- Frequency Analysis
- Operation History

## Technology Stack
- React
- Vite
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
